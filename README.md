# Telecom-Customer-Churn-Prediction-Project
• Analyzed the customer demographics, services, tenure, charges, contracts, and billing patterns through Exploratory Data
Analysis and data preprocessing, found the relationship between the features and the churn by plotting the correlation heatmap
• Conducted outlier detection using the IQR method, encoded categorical variables and standardized the numerical features.
• Analyzed Logistic Regression, Decision Tree, Random Forest and KNN models, applying GridSearchCV for hyperparame-
ter tuning and comparing model performance using accuracy and F1-score for reliable and consistent model comparision
• Logistic Regression achieved 0.82 accuracy and 0.60 F1-score, effectively identifying customers who are likely to churn
